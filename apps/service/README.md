# Altora Service

**Altora Service** adalah vertikal aplikasi SaaS ERP Altora yang dirancang khusus untuk bisnis berbasis layanan (barbershop, salon, spa, klinik kecantikan, bengkel, pet grooming, dan jasa profesional).

## Fitur Utama
- **Katalog Layanan & Durasi**: Mengelola item jasa dengan durasi dan estimasi pengerjaan.
- **Penugasan Staf & Komisi**: Penugasan kapster/terapis/teknisi per baris layanan dengan perhitungan komisi otomatis.
- **Keranjang Campuran (Service + Retail)**: Transaksi tunggal untuk paket potong rambut + pomade dalam 1 invoice.
- **Konsumsi Stok Bahan**: Konsumsi stok cat rambut, shampoo, atau bahan otomatis terhubung ke `@altora/inventory-core`.
- **Konsumen Platform Bersama**: Mengonsumsi `@altora/pos-ui`, `@altora/pos-core`, `@altora/control-plane-core`, dan `@altora/inventory-core`.
