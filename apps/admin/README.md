# Altora Admin

Area internal Super Admin Altora. Ini bukan halaman administrasi untuk pemilik
toko dan tidak boleh dicampur ke Market atau Resto.

## Jalankan lokal

```bash
npm run dev:admin
```

Admin memakai port `3003`.

Otorisasi, audit privileged action, dan data operasional Super Admin akan
dipindahkan dari donor secara terpisah setelah produk operasional selesai.
