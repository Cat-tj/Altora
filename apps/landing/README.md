# Landing Altora

Satu-satunya landing publik umum untuk `altora.my.id`. Landing ini menjelaskan
suite Altora dan mengarahkan pengguna langsung ke halaman login masing-masing
produk.

## Jalankan lokal

```bash
npm run dev:landing
```

Landing memakai port `3000`.

Jangan membuat landing umum kedua di aplikasi produk. Subdomain produk hanya
menjadi pintu login dan aplikasi terautentikasi, bukan situs pemasaran suite
yang terpisah.
